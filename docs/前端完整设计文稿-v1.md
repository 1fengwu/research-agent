# AutoResearch 前端完整设计文稿 v1

**状态**：待审查  
**目标**：让 AutoResearch 的单页 Streamlit 评审工作台，能够完整演示 A/B/C/D 四个角色的全部核心功能，并把“研究闭环、预算控制、验证、复现、降级”五件事全部可操作地展示给评审。

---

## 1. 设计定位

前端是 D 的“薄壳”，只做四件事：

1. 读 A 的事件流，展示研究进度、阶段、决策原因；
2. 读 B 的数据摘要，展示数据画像、特征、标签、切分摘要；
3. 读 C 的指标与 verdicts，展示前置门、三臂对照、独立测试、复现包；
4. 提供创建任务、导入 CSV、启动研究、下载报告和复现包的入口。

前端不做任何研究决策，不写 holdout，不调用 LLM，不生成 verdict。

---

## 2. 页面信息架构

### 2.1 顶部导航区

- 产品名：AutoResearch 研究验证工作台
- 数据来源：离线演示 / `.arc` 真实事件 / 上传 CSV
- 运行选择：按 `run_id` 切换多轮运行
- 状态摘要：阶段、停止原因、剩余预算
- 现场模式标识：`离线回放` / `真实研究` / `实时运行中`

### 2.2 三个主标签页

#### 创建任务

用途：配置研究任务并启动。

包含：

- 数据来源选择：内置演示数据 `data/demo_panel.csv` 或上传合规 CSV；
- 上传预览：行数、字段、日期范围、缺失率、`(date,symbol)` 唯一性；
- 任务参数：任务 ID、标签窗口、seed；
- 预算参数：候选实验数、云调用数、云 token 上限、墙钟时间；
- 前置门摘要：可展示 `pre_gate.json` 的两窗 AUC、CI、排除数、结论；
- 启动按钮与启动结果：
  - 离线联调：把 mock 事件复制到 `.arc/demo/`；
  - 真实运行：后台子进程执行 `autoresearch.cli run`。

#### 跟踪研究

用途：逐轮观察研究过程。

包含：

- 研究时间线：
  - 基线 → 假设预注册 → 候选实验 → 验证 → 修正 → 锁定 → 独立测试；
  - 每条事件展示阶段、事件类型、实验编号、决策原因、剩余 token；
  - 证据驱动修正时突出显示 `research.revised` 事件。
- 假设与证据：
  - 预注册假设列表；
  - 证据编号；
  - 已淘汰/被反驳的假设；
  - 每个实验对应的假设与配置。
- 实验结果：
  - 实验 ID、假设、特征/模型配置、val1/val2 AUC、verdict、错误信息；
  - 0.01 窗口下滑导致的 `refuted` 用醒目状态显示。
- 预算面板：
  - 阶段；停止原因；
  - 剩余实验数、剩余云调用、剩余 token、剩余秒数；
  - `budget_blocked` 时显示拦截原因。
- 自动刷新开关：默认关闭，开启后 2 秒轮询事件文件。

#### 审查结论

用途：展示研究结论和可交付物。

包含：

- 固定基线 vs 锁定候选：
  - merged AUC、val1/val2 AUC；
  - 保留基线或锁定候选的理由；
- 独立测试：
  - verdict：`supported / refuted / inconclusive / blocked / partial_completed`；
  - 测试 AUC、有效天数、排除样本；
  - 只显示锁定后的一次测试结果；
- 下载区：
  - Markdown 报告；
  - 复现包 zip：事件流、报告、数据哈希、切分、种子、运行命令；
- 三臂对照摘要：可从 C 的 `metrics.json / metrics.csv` 展示 A/B/C 三臂完成率、AUC、token、时间。

### 2.3 侧边栏

- 数据源；
- 运行列表；
- 当前运行阶段；
- 当前停止原因；
- 低预算演示入口；
- CLI 回放命令提示。

## 4. 用户流程

### 4.1 完整离线演示

1. 选择“离线演示（mock_events.json）”；
2. 创建任务：内置演示数据，候选 4、云 token 6000；
3. 启动研究：页面复制 mock 事件到 `.arc/demo/`；
4. 跟踪研究：查看完整时间线、假设、证据、预算；
5. 切换到低预算运行，展示 `budget_blocked`；
6. 审查结论：基线与锁定候选、独立测试；
7. 下载报告与复现包；
8. 打开 CLI 回放命令演示降级路径。

### 4.2 真实后台运行

1. 数据源选择 `.arc` 或启动真实研究；
2. 页面写入 `task.json`，启动 `autoresearch.cli run`；
3. 页面轮询 `.arc/runner-events.jsonl`；
4. 运行中实时展示事件流与预算；
5. 完成后进入审查结论并下载复现包。

### 4.3 上传 CSV

1. 上传合规 CSV；
2. 页面展示上传预览；
3. 列名映射失败或缺少字段时显示明确错误；
4. 校验通过后启动真实研究；
5. 后续流程与真实运行一致。

## 5. 视觉与交互设计

### 5.1 风格

- 研究/评审工具属性，采用“工作台”风格，不做营销页；
- 高信息密度，但保持分栏和分组清晰；
- 主色：中性底色 + 蓝/青作为信息色，用琥珀色标记预算风险，用红色标记错误/refuted，用绿色标记完成/支持；
- 表格、指标卡、时间线为主要展示形式；
- 状态用文字 + 色块标识，不依赖用户去读报告正文。

### 5.2 布局约束

- 1280px 以上使用 `st.columns` 分栏：
  - 跟踪研究：左侧时间线，右侧预算面板；
  - 审查结论：三列指标 + 下载按钮；
- 窄屏自动堆叠；
- 时间线事件和实验表格保持固定列宽，长文本截断或换行，不允许撑破页面。

### 5.3 组件

- 阶段徽标：`UNSEEN / PLANNING / PLANNED / EXPERIMENTING / VERIFIED / REVISED / LOCKED / TESTED / PASSED / CONVERGED / FAILED / PARTIAL_COMPLETED`；
- 状态徽标：`supported / refuted / inconclusive / blocked / partial_completed`；
- 预算进度条：候选、云调用、token、时间；
- 事件时间线：时间、阶段、事件类型、决策原因；
- 实验表格：ID、假设、配置、AUC、verdict；
- 下载按钮：报告与复现包；
- 错误/警告条：上传失败、事件加载失败、后台启动失败、复现包生成失败。

## 6. 状态与异常设计

| 状态 | 页面表现 |
|---|---|
| 无事件 | 创建任务为空，跟踪/审查显示引导 |
| 运行中 | 时间线实时增加，预算减少，阶段变化 |
| 完成 | 显示 TESTED、最终 verdict、可下载 |
| 部分完成 | 显示 PARTIAL_COMPLETED 与停止原因 |
| 预算拦截 | 显示拦截原因和剩余预算 |
| 事件文件损坏 | 侧边栏显示加载错误，保留创建任务可用 |
| 后台启动失败 | 创建任务显示错误，不进入跟踪 |
| UI 异常 | 页面显示 CLI 回放命令，保证评审可继续 |

## 7. 数据边界

前端只读取：

- `.arc/runner-events.jsonl`；
- `.arc/demo/task.json`；
- `data/demo_panel.csv` 或上传 CSV；
- `.arc/pre_gate.json`；
- `.arc/eval/metrics.json`、`metrics.csv`；
- `mock_events.json`。

前端不写入：

- holdout；
- verdict；
- token ledger；
- 研究结论。

前端写出的只有演示任务文件、上传文件、复现包和报告文件，且都位于 `.arc/` 或下载目录。

## 8. 三分钟评审演示脚本

### 0:00-0:30 创建任务

- 数据源选择“离线演示（mock_events.json）”；
- 展示内置演示数据画像；
- 设置预算：候选 4、云 token 6000；
- 启动研究；
- 显示任务已保存到 `.arc/demo/`。

### 0:30-1:30 跟踪研究

- 选择完整运行 `R20261114-001`；
- 展示时间线：基线 → 假设 → 实验 → REVISED → LOCKED → TESTED；
- 展示预算面板：剩余实验、云调用、token、时间；
- 切换到低预算运行 `R20261114-002`；
- 展示 `budget_blocked:cloud_token_reserve_exhausted` 与 `PARTIAL_COMPLETED`。

### 1:30-2:20 审查结论

- 展示固定基线与锁定候选的 merged AUC 对比；
- 展示独立测试 verdict 与测试 AUC；
- 点击下载 Markdown 报告；
- 点击下载复现包 zip；
- 简要说明复现包内容。

### 2:20-3:00 CLI 降级

- 打开终端执行 `python -m autoresearch.cli demo`；
- 展示相同事件流的 CLI 时间线；
- 说明真实后台入口：

```bash
python -m autoresearch.cli run --task .arc/task.json --oracle autoresearch.oracle:ResearchOracle
```
